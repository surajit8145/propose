## ✨ Features

- 💖 **Cinematic Multi-Scene Journey**:
  1. **Welcome Scene** — Animated typewriter typography, ambient glow orbs, and floating rose petals.
  2. **The Love Letter** — Interactive wax-sealed envelope with heart-felt revelation.
  3. **The Proposal** — The ultimate question with playful interactive responses & celebratory confetti / fireworks.
  4. **Our Memories** — Interactive photo gallery with memory cards and romantic polaroids.
  5. **Forever & Always** — Time counter of love, sweet promises, and star-filled celebration.
- 🎵 **Built-in Romantic Audio Engine**: Ambient synthesized chimes, melodic harp tones, and chime effects via Web Audio API without requiring external audio files.
- 🌸 **Particle & Ambient Canvas Engine**: Floating petals, drifting hearts, dynamic twinkling starfields, and ambient glowing orbs.
- 📱 **Fully Responsive**: Optimized for desktop, tablets, and mobile screens.
- 🚀 **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript.

## 🚀 Quick Start (Run Locally)

1. Clone or download this repository:
   ```bash
   git clone https://github.com/surajit8145/propose.git
   cd propose
   ```

2. Open `index.html` directly in your favorite web browser (Chrome, Edge, Firefox, Safari) or use Live Server in VS Code.

---

## 🌐 Deploy to GitHub Pages (Free Live Website)

You can host this project online for free using **GitHub Pages**:

1. Push this repository to GitHub.
2. Go to your repository on GitHub.
3. Click on **Settings** > **Pages** (in the left sidebar).
4. Under **Branch**, select `main` (or `master`) branch and `/ (root)` folder.
5. Click **Save**.
6. Wait 1-2 minutes, and your live romantic webpage will be published at:
   ```
   https://surajit8145.github.io/propose/
   ```
